# Web Development Projects

A collection of web development projects and practice applications built while learning and exploring **HTML, CSS, JavaScript, Node.js, and Express.js**.

## Projects

### 🎨 Basic HTML & CSS

A collection of basic HTML and CSS practice projects focused on layouts, styling, images, and frontend fundamentals.

**Technologies:** HTML, CSS

---

### 🎯 Guessing Game

A simple JavaScript-based guessing game created while learning JavaScript fundamentals and user interaction.

**Technologies:** HTML, JavaScript

---

### 🧠 Simon Game

An interactive Simon Says memory game where the player follows an increasing sequence of colors.

**Technologies:** HTML, CSS, JavaScript

---

### 🎵 Spotify Clone

A frontend recreation of the Spotify web player interface created to practice webpage layouts, styling, navigation components, cards, and responsive design.

**Technologies:** HTML, CSS, Font Awesome

---

### 🎨 Creativity — CRUD Application

An Express.js application for creating and managing artwork posts. The project includes CRUD operations, image uploading, editing, deleting, and viewing individual posts.

**Technologies:** Node.js, Express.js, EJS, Multer, UUID, Method Override
